# God-Tier macOS Development Environment - Concise Context

> A reproducible, user-space macOS development environment using Mise as the central orchestrator. Strict hierarchy: Mise > Bun > Pixi > Uv. Zero system modifications - everything installs to ~/.local.

## Quick Reference

| Field | Value |
|-------|-------|
| Project | God-Tier macOS Development Environment |
| Core Principle | Mise-first orchestration |
| Hierarchy | Mise > Bun > Pixi > Uv |
| Location | User-space only (~/.local, ~/.config) |
| System Mods | Zero sudo, zero Homebrew (except GUI apps) |

## Tool Hierarchy

| Level | Tool | Purpose |
|-------|------|---------|
| 1 | Mise | Global orchestrator, manages ALL tools |
| 2 | Bun | JavaScript/TypeScript (replaces Node/npm) |
| 3 | Pixi | Binary packages (conda-forge) |
| 4 | Uv | Python packages (10x faster than pip) |

## Critical Rules

1. NEVER use sudo - Everything is user-space
2. NEVER install globally with npm/pip - Use mise (`mise use -g`)
3. NEVER modify system Python/Node - Mise manages versions
4. NEVER commit secrets - Use op://, infisical, or mise secrets
5. ALWAYS use mise tasks - Not raw commands
6. ALWAYS run tests before committing - `bats tests/`

## Tool Installation Pattern

```bash
# Correct
mise use -g <tool>
mise use -g "npm:<package>"
mise use -g "pipx:<package>"

# WRONG (never do this)
npm install -g <package>
pip install <package>
brew install <cli-tool>
```

## Mise Settings (from config/mise.toml)

```toml
[settings]
experimental = true
not_found_auto_install = true

[settings.npm]
bun = true                    # npm -> bun
package_manager = "bun"

[settings.python]
uv_venv_auto = true           # pip -> uv
```

## Secrets Management

1. **1Password** (Recommended): `op://Private/Anthropic/credential`
2. **Infisical**: `infisical run -- ./script.sh`
3. **Mise Native**: `mise secrets set KEY=value`

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Command not found | `eval "$(mise activate zsh)"` then `mise reshim` |
| Wrong version | `mise ls` then `mise trust` |
| Config not loading | `cp config/mise.toml ~/.config/mise/config.toml` |
